# 🫁 صيدلية الجهاز التنفسي - نظام إدارة الصيدلية

نظام إدارة متكامل لصيدلية الجهاز التنفسي بكوبري القبة

## المميزات
- 🧾 تسجيل المبيعات وإصدار الفواتير
- ↩️ تسجيل المرتجعات
- 📦 إدارة المخزون الكاملة
- 🛒 تسجيل المشتريات
- 👥 سجل العملاء
- ⚠️ متابعة تواريخ الصلاحية
- 💸 تسجيل المصروفات
- 📊 تقارير مفصلة
- 📋 طلبيات مقترحة تلقائياً
- 🖨️ طباعة الفواتير
- 💾 نسخ احتياطي تلقائي

## تحميل البرنامج
اذهب إلى [Releases](../../releases) وحمّل آخر ملف `Setup.exe`

## بيانات الدخول الافتراضية
| المستخدم | كلمة المرور | الصلاحية |
|----------|------------|---------|
| admin | admin123 | مدير كامل الصلاحيات |
| sales | sales123 | موظف مبيعات فقط |

> ⚠️ **مهم:** غيّر كلمة المرور بعد أول تشغيل من الإعدادات

## متطلبات التشغيل
- Windows 10 أو أحدث (64-bit)
- لا يحتاج أي برامج إضافية
