# 🫁 صيدلية الجهاز التنفسي - نظام إدارة متكامل

## 📥 تحميل البرنامج

### الملفات الجاهزة للتحميل:

**اختر أحد الخيارين:**

1. **Setup.exe** (Installer الاحترافي)
   - ✅ يثبت البرنامج على الكمبيوتر
   - ✅ يتذكر البيانات بعد غلق البرنامج
   - ✅ يسهل إزالته من Control Panel
   - 💾 حجم الملف: ~200MB

2. **صيدلية الجهاز التنفسي.exe** (البرنامج المباشر)
   - ✅ بدون تثبيت - شغله مباشرة
   - ✅ يعمل من أي مجلد
   - 💾 حجم الملف: ~180MB

## 🚀 خطوات البناء المحلي

إذا أردت بناء البرنامج بنفسك:

### المتطلبات:
- ✅ Windows 10/11 (64-bit)
- ✅ Node.js v14+ (https://nodejs.org/)
- ✅ 2 GB مساحة خالية
- ✅ اتصال إنترنت سريع

### خطوات البناء:

```bash
# 1. استنساخ المشروع
git clone https://github.com/ka22jr/---.git
cd ---
git checkout build-exe

# 2. تشغيل البناء التلقائي (الأسهل!)
node auto-build.js

# أو يدوياً:
node setup.js
npm install
npm run build
```

### ستجد الملفات المبنية في مجلد: `dist/`

## 💾 حفظ البيانات

البيانات تُحفظ تلقائياً في:
```
C:\Users\YourName\AppData\Local\pharmacy-system\
```

النسخ الاحتياطية تُحفظ في نفس المجلد.

## 📞 الدعم والمساعدة

### المشاكل الشائعة:

**❌ البرنامج لا ينطلق**
- تأكد من تثبيت Windows 10 أو أحدث
- قد تحتاج تثبيت Microsoft Visual C++ Redistributable

**❌ خطأ في قاعدة البيانات**
- احذف ملف pharmacy.db من AppData\Local\pharmacy-system\
- شغّل البرنامج مرة أخرى

**❌ بطء في الحفظ**
- هذا طبيعي عند الحفظ الأول
